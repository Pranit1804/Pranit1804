### 🍎 [Flutter Cupertino Symbols](https://pub.dev/packages/flutter_cupertino_symbols) — Open Source Flutter Package
> Published on pub.dev

- **6,843 SF Symbols 6 icons** as native `IconData` constants — the full Apple icon set for Flutter
- Works with Flutter's built-in `Icon`, `IconButton`, `ListTile` — **zero custom widgets, zero runtime overhead**
- Tree-shakable, type-safe, with IDE autocomplete via `SFSymbols.*` constants
- Zero dependencies beyond Flutter itself; MIT licensed; supports iOS, macOS, Android, Web, Linux, Windows
